# Ahmed Samer — Portfolio

A lightweight, responsive portfolio built with plain HTML, CSS, and JavaScript.

The site highlights:

- Professional software-engineering experience
- Fintech and payments work
- Interview Intelligence and LeadAtlas
- Selected public engineering and AI projects
- Hackathon and competitive-programming achievements
- Engineering stack and current AI focus
- Live GitHub statistics and activity
- Codeforces and LeetCode profiles

## Run locally

Open `index.html` directly, or serve the folder with any static HTTP server.

For example:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## GitHub Pages

This project intentionally has no build step. It can be published directly from a GitHub branch/folder using GitHub Pages.
