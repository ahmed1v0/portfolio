## Concept

Living Blueprint: an engineering laboratory expressed through isometric planes, registration marks, precise annotations, and a central four-point signal. Extend the hero into a project-aware lens. Selecting a real project and a technical layer reveals how that project's documented technologies connect, with a direct route to its project notes. Default descriptions and all project content remain available without scripts. No simulated live metrics, fabricated screenshots, or speculative architecture.

The visual progression is dark studio → ivory Interview Intelligence composition → lavender LeadAtlas map → compact project index → open editorial story → connected career milestones → technical ecosystem → dramatic closing scene. Project art is original CSS/SVG, explicitly conceptual.

## Seven phases

1. Creative direction: document critique, concept, constraints, and validation.
2. Cinematic hero: spatial lighting, responsive depth, stronger installation typography and framing.
3. Premium projects: differentiated large project compositions and expandable technical stories.
4. Signature interaction: integrate the project-aware Living Blueprint into the hero.
5. Motion system: finite entrance choreography, pointer-capable perspective, scroll progress, reduced-motion and cleanup.
6. Creative refinement: about, experience, skills, achievements, contact, resilient activity, metadata, and reusable source cleanup.
7. Production validation: syntax/static integrity, local performance evidence, desktop/tablet/mobile inspection, keyboard and interactive workflows, source-level accessibility checks, and honest limitations.

Each completed phase is committed separately. Preserve the original brief's professional content, nine projects, available links, resume, and deployment model. No new runtime packages, hosted services, external publication, or invented contact data.

## Performance and accessibility

Use vector geometry, shared CSS motion tokens, and requestAnimationFrame only on input/scroll. No perpetual JavaScript loop, scroll hijacking, or custom cursor. Disable perspective and motion for reduced-motion/coarse-pointer users. Menus, native disclosures, buttons, and select controls retain their keyboard behavior. Test failure states for optional remote statistics. Do not equate local inspection with field Core Web Vitals certification.
